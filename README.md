### qt_web_engine_widgets

This repository contains the qt_web_engine_widgets crate.
This crate contains bindings for [QtWebEngine](https://wiki.qt.io/QtWebEngine) generated using [ritual](https://github.com/rust-qt/ritual) and is meant to complement the [other ritual generated crates](https://rust-qt.github.io/qt/) like [qt_core](https://docs.rs/qt_core/latest/qt_core/), [qt_gui](https://docs.rs/qt_gui/latest/qt_gui/) and [qt_widgets](https://docs.rs/qt_widgets/latest/qt_widgets/).
For that the [fork by snuk182](https://github.com/snuk182/ritual) was used.

It depends on the [qt_web_engine](https://github.com/gelaechter/qt_web_engine) crate.
